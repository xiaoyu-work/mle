# MLE - Make Life Easier

A lightweight Windows selection translator written in Rust. Select text, hold
the right mouse button, and get a Chinese translation in a compact popup.

## Features

- Offline English-Chinese dictionary with online translation for words and sentences.
- Custom keyboard shortcuts with conflict detection.
- Selectable, copyable translations and adjustable text size.
- Native Windows interface that stays in the notification area.
